# HTML & CSS Practice

Welcome to the **HTML & CSS Practice** folder! This repository is a collection of practice files and mini-projects to improve your frontend development skills using HTML and CSS.

## 📁 Folder Structure


## 🛠 Skills Practiced

- HTML5 structure and semantics
- CSS3 styling and box model
- Flexbox and Grid layout techniques
- Responsive web design
- Component-based UI design
- Forms and input styling

## 🔧 How to Use

1. Clone this repository or download the ZIP file.
2. Open the project folder with any code editor (e.g., VS Code).
3. Open the individual `.html` files in a browser to see the output.
4. Edit and experiment to improve your skills.

## 📌 Notes

- Each folder contains a `README.md` or comments in the code explaining the concepts.
- No JavaScript is included; focus is purely on HTML and CSS.
